# ClearBuildIT Landing

Rebranding van een starttemplate naar **ClearBuildIT**: maatwerk SaaS-platformen, websites, webapps en mobile apps.

## Stack
- Vite + React 18
- Tailwind CSS (custom theming)
- Headless UI + Heroicons (navigatie & iconen)

## Installatie
```bash
npm install
npm run dev
```

## Structuur
```
src/
  components/      -> UI componenten (Navbar, LocationSelect, ServicesCard)
  sections/        -> Pagina secties (Hero)
  styles/          -> Globale CSS & Tailwind directives
  assets/          -> Afbeeldingen / media
```

## Volgende uitbreidingen
- Cases sectie + proces tijdlijn
- Contact formulier (serverless / form backend)
- Tech stack grid (React, Node, Python, Cloud)
- Blog en CMS integratie (bijv. headless)
