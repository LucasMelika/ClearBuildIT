Google Site Verification File

This file is used to verify ownership of your website with Google Search Console.

You can replace the content attribute with your actual Google verification code from Google Search Console.

Instructions:

  1. Go to Google Search Console
  2. Add your property (https://clearbuildit.nl)
  3. Choose "HTML file" verification method
  4. Download the HTML file from Google
  5. Replace the content in this file with the verification code from Google's file
  6. Keep this file in the /public folder
  7. Click "Verify" in Google Search Console
